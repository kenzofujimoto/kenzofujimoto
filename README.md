## How I work with AI

**Problem → requirements → prototype → test → security review → deploy → iterate.** I use ChatGPT, Claude/Codex-style coding agents and LLM tools to speed up implementation and research. My role includes defining the product, evaluating generated code, integrating services, addressing failures, documenting trade-offs and deciding when a feature is ready.

- **AI and data:** Retrieval-augmented generation (RAG), LLM APIs, vector search, document ingestion, Python, SQL.
- **Product engineering:** React, TypeScript, Next.js, FastAPI, REST APIs, PostgreSQL, Supabase, IndexedDB.
- **Delivery and quality:** Docker, GitHub Actions, automated tests, Playwright, security checks, CI/CD.
- **Security:** Entra ID / Microsoft 365, endpoint security, Wazuh, CrowdStrike, IAM and access controls.
- **Agent workflows:** role-based AI agents, scoped prompts, context handoffs, test-driven implementation, MCP integrations and approval checkpoints. [See sanitized workflows and prompt examples](AI_WORKFLOWS.md).
- **Open-source tooling:** [my versioned agent-skills repository](https://github.com/kenzofujimoto/agent-skills) and [Caveman](https://github.com/JuliusBrussee/caveman) as an external efficiency reference. I do not claim authorship of third-party frameworks.
